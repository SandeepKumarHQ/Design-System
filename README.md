# SandeepKumarHQ Design System

One recognizable visual language for professional website, GitHub diagrams, LinkedIn explainers, newsletter assets, enterprise consulting reports and slide decks.

**Direction v0.1 (proposed):** precise technical documentation feel; near-monochrome light surfaces, dark ink, restrained electric-blue semantics, sharp structured shapes, diagram-first information hierarchy. Avoid ornamental gold, decorative stock imagery and meaningless AI icon clouds.

## Source of truth
- `tokens/tokens.css`: preliminary color, spacing, typography and surface tokens.
- `docs/visual-language.md`: editorial hierarchy and visual rules.
- `docs/diagram-standard.md`: semantically meaningful system architecture diagrams.
- `templates/CAROUSEL.md`: publishable visual QA contract.

Research-based design findings and real A/B/outcome evidence must become Knowledgebase contributions; this repository owns visual *rules*, not source research. Content Studio and Newsletter derive output variants from here.

**Status:** foundations only; final brand assets and production component implementation remain unverified.
