# Visual and editorial foundations

Sharp clear layouts; diagram/typography over decoration. Headings Poppins, body Inter with system fallbacks. White/light neutral main surfaces, dark text, blue solely for meaning/interaction. No stock robot portraits, glowing brains, circuit clouds, gold gradients or irrelevant metaphor scenes.

Accessibility: high text contrast, clear focus indicators, reduced motion, labels not color-only, no low-resolution labels, protect crop-safe zones. Use SVG for original architecture diagrams; WebP for editorial raster images. Explain what the diagram teaches.

Surfaces: LinkedIn 1:1 or portrait, newsletter responsive, website desktop/mobile, reports print/PDF. These are target format requirements, not fabricated validated exports.

Original diagram facts come from Knowledgebase IDs; approved brand choices are owned by Design-System. Track clarity/reading issues as design-learning contribution envelopes.
